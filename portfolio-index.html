Free.Shelf
A free-games tracker that pulls this week's markdowns from Steam and Epic Games into one shelf. Filter by store, sort newest/oldest/A→Z, and browse without hunting across two separate storefronts. Live deal data comes from a backend proxy, with a sample-data fallback so the UI never breaks if the API's down.
JavaScript Node.js HTML/CSS
  • Aggregates free-game promotions from Steam and Epic Games into a single view
  • Store filters (Steam / Epic) plus sort by newest, oldest, or A→Z
  • Backend proxy pulls live deal data, with graceful fallback to sample data
  • Empty and loading states designed in, not bolted on
